# Windows installer

Download `AImana-Setup.exe` and double-click it. The wizard installs for your Windows user and asks where to publish `usage-relay.json`. If SmartScreen appears because this installer is unsigned, click **More info → Run anyway**. In AI·mana on your phone, open **Settings › Your computer › Choose relay file…** and select the file in the chosen folder's `AImana` subfolder.

The Start menu has **AI·mana — check setup** and **AI·mana — set up again**. Uninstall removes the scheduled task and restores your previous Claude Code statusline while retaining your relay data.
